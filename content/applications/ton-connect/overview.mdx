## What TON Connect is

**TON Connect** is the standard wallet connection protocol for the TON blockchain.

It links a dApp to a user's wallet over an end-to-end encrypted session so the app can read the connected address, request signatures, and send transactions — without ever touching the user's keys.

<Callout type="note">
  TON Connect does not provide deeper integrations with the TON blockchain. Implement them [manually](/applications/ton-connect/deep/overview).
</Callout>

### Build a wallet

TON Connect does not provide an SDK for wallets. If you're a wallet developer, implement the protocol [directly](/applications/ton-connect/deep/overview) based on the [specification](https://github.com/ton-blockchain/ton-connect).

When using TypeScript, prefer utilizing interfaces from [`@tonconnect/protocol`](/applications/ton-connect/api-reference/protocol).

See the [manual implementation guides](/applications/ton-connect/deep/overview) for more.

<Callout type="tip">
  Explore an [open-source wallet implementation](https://github.com/mytonwallet-org/mytonwallet) that supports TON Connect and deeper TON blockchain integrations.
</Callout>

## API reference

The dApp-facing packages live in the [`ton-connect/sdk` monorepo on GitHub](https://github.com/ton-connect/sdk):

- [`@tonconnect/ui-react`](/applications/ton-connect/api-reference/ui-react) — hooks and prebuilt components for React.
- [`@tonconnect/ui`](/applications/ton-connect/api-reference/ui) — framework-agnostic UI, same components without React bindings.
- [`@tonconnect/sdk`](/applications/ton-connect/api-reference/sdk) — headless connector for server-side flows or custom UI.
- [`@tonconnect/protocol`](/applications/ton-connect/api-reference/protocol) — wire-format types and session cryptography for wallet/SDK implementers.
