## SDKs

There are many libraries for accessing and interacting with blockchain in dApps and tools written in various programming languages: [SDKs](/applications/sdks). For an overview of the blockchain APIs that many SDKs are built around, see the [API overview](/api/overview).

## TON Connect

[TON Connect](/applications/ton-connect/overview) is the standard wallet connection protocol for the TON blockchain. It enables applications and wallets to communicate with each other in a standardized way.

- Specification repository on GitHub: [`ton-blockchain/ton-connect`](https://github.com/ton-blockchain/ton-connect)
- NPM packages:
  - [`@tonconnect/ui-react`](/applications/ton-connect/api-reference/ui-react) — hooks and prebuilt components for React
  - [`@tonconnect/ui`](/applications/ton-connect/api-reference/ui) — framework-agnostic UI, same components without React bindings
  - [`@tonconnect/sdk`](/applications/ton-connect/api-reference/sdk) — headless connector for server-side flows or custom UI
  - [`@tonconnect/protocol`](/applications/ton-connect/api-reference/protocol) — wire-format types and session cryptography for wallet and SDK implementations

Read more about [TON Connect](/applications/ton-connect/overview).
